# Commitovací strategie

Tento projekt používá [Conventional Commits](https://www.conventionalcommits.org/).

## Formát

<typ>(<scope>): <popis v češtině nebo angličtině>

## Typy

- feat – nová funkce
- fix – oprava chyby
- test – testy
- refactor – přepis bez změny chování
- docs – dokumentace
- chore – závislosti, konfigurace
- style – formátování

## Příklady

feat(notes): add create note form
fix(auth): handle empty password error
test(notes): add unit tests for getNoteById
chore(deps): update react to 18.3
